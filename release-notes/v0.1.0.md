## Lumen 0.1.0

Lumen 的第一个公开版本：一套面向 iOS / macOS 的 UI 调试工具，包含 macOS 图形客户端、`lumen` 命令行与 MCP 服务，以及嵌入被调试 App 的采集端 LumenServer。

### 查看与调试
- 2D / 3D 层级画布（Metal 渲染），间距测量、隐藏节点、边框线、3D 层次感
- 层级大纲与属性检查器，选择器查询（类名、`#identifier`、`[text*="登录"]`、`:visible`、组合）
- SwiftUI 逻辑视图树：`Text` 文字、控件、修饰符链与参数、`@State` 等调试数据
- 运行时改属性、调用方法、开关手势，修改记录可撤销、可复制为 AI 提示
- Auto Layout 约束与歧义诊断、点击诊断（hit-test 与响应链）、无障碍元素、外观覆盖（深色、字号、RTL）
- 审计：触控区域、文字截断、对比度、遮挡、布局歧义、无障碍缺失等，可用于 CI
- 时间轴回看与差异对比、设计稿叠加与差异对比、`.lumen` 完整归档离线打开

### 连接
- 本机（macOS App、iOS 模拟器）、USB 真机、可选的局域网 Bonjour
- 零改动注入：`lumen launch --mac` / `--simulator`

### AI 助手
- `lumen mcp`：层级、查询、截图、快照对比、审计、hit-test、约束、无障碍、改属性、调用方法、源码定位等工具

### 接入
- Swift Package Manager：`https://github.com/wangwanjie/Lumen`，产品 `LumenServer`
- CocoaPods：`pod 'LumenServer', :configurations => ['Debug']`
- 只应在 Debug 构建中集成；默认只接受本机与 USB 连接
