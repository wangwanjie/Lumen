## Lumen 0.3.5

### 画布
- 遮罩（layer.mask / UIView.mask）始终按 App 里的样子显示：底色为方块、靠圆形遮罩显示成圆盘的视图，以及 Lottie 用遮罩挖出形状的图层，不再受“显示被裁剪的内容”影响；该开关只控制 clipsToBounds、滚动视图可见区域之外的内容
- 圆角加 clipsToBounds 的容器把子节点裁成圆角（只圆部分角时下角保持直角，如底部弹层），“显示被裁剪的内容”开启时不裁

### 采集端（LumenServer / LumenLite）
- 节点新增可选的 `maskedCorners`（哪些角是圆角），完整采集端与 LumenLite 均导出
- 新增 LumenLite：线上版本可用的轻量导出库（iOS / Mac Catalyst，纯 Objective-C 静态库），把指定 UIWindow / UIViewController / UIView 导出为 .lumen 离线归档，支持截屏时自动导出；接入方式见官网与发布仓库 README
- LumenLite 导出补全：节点遮罩（含逐像素形状）、Metal / 视频等只在屏幕合成结果里的内容（如 MTKView）从屏幕补画进单层纹理

### 离线归档
- 读取 .lumen 格式版本 2：JSON 分段压缩、相同纹理共用数据（Lumen.app 与命令行自己写出的仍是版本 1）
