## Lumen 0.2.0

### 界面重新设计
- 侧栏大纲：节点类别图标、层级引导线与自适应缩进，列表单元格显示 section / row，位置徽标改为紧凑的“0 · 2”；修复悬停底色残留与类名横向截断
- 属性检查器、工具栏目标选择器与设置窗口重新设计
- 画布：胶囊浮动工具条、缩放控件、点阵背景，3D 模式自动适配；底部面板重新设计，工具栏新增“面板”按钮，一键显示或隐藏控制台、时间轴、点击诊断与修改记录
- 状态栏、窗口过渡与提示横幅重新设计；未连接状态页改为雷达扫描动画与接入方式卡片
- 新增使用向导：分步介绍接入、连接、画布操作、检查与修改，首次启动自动弹出，可在帮助菜单重新打开

### 操作
- 3D 视图中触控板双指滑动改为平移画布，旋转用拖动（⌥ 双指滑动仍可旋转）

### 接入
- 新增一键接入脚本 `lumen_setup.py`：在工程目录运行即可让 App 在 Debug 下集成采集端，不改 Podfile、Package 或代码，支持 `--remove` 原样撤销与 CocoaPods 钩子
- 采集端新增 Objective-C 入口类 `LumenServer`（`start` / `startAllowingNetworkConnections:` / `stop`），ObjC 工程无需 Swift 桥接文件
- 新增 ObjC、Swift、SwiftUI 与混编四个 iOS 示例工程

### AI 助手
- 官网与 README 补充 Codex、ChatGPT 桌面 App 的 MCP 接入方式，新增“用 AI 排查、写页面、改 bug”使用示例
- 官网：https://lumen.vanjay.cn
