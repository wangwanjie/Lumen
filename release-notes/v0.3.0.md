## Lumen 0.3.0

演示视频与图文介绍见官网：https://lumen.vanjay.cn/#new

### 启动调试
- 新增“启动调试”窗口（⌘N）：不改工程，注入采集端并启动 Mac 应用（含 Mac Catalyst）、模拟器中的 App、iOS 安装包与 USB 真机上的 App，成功后自动连接；最近启动可一键重启，“重新启动当前 App”（⌥⌘R）恢复选中的节点
- iOS 安装包可在 Apple 芯片的 Mac 上直接运行，可按 iPhone 机型或自定义尺寸运行，默认隐藏窗口标题栏、禁用最大化；拖入 `.ipa` 时询问在本机还是真机运行
- 真机借 Xcode 中登录的 Apple ID（免费账号即可）自动重签安装，到期前一天提醒续签；瘦身包可装到任意机型，缺失权限的重签不再闪退
- Hardened Runtime 的 Mac 应用自动重签副本，原 App 不改动；无法启动时说明原因并给出可一键执行的处理
- 命令行 `lumen launch` 支持 `--mac`、`--simulator`、`--ios`、`--device`、`--resign`、`--iphone-model`、`--device-size` 等

### 应用日志
- 底部“应用日志”面板显示 stdout / stderr 与 os_log；集成了 LumenServer 的 App 经 Lumen 连接推送日志，不经启动调试也能看，断线重连只补发错过的部分
- 虚拟化列表应对大量日志；文本筛选、来源与级别过滤、白名单与黑名单规则（支持正则），右键把选中文本或子系统加入规则

### 检查器
- 几何读数卡：父视图与所选节点的尺寸、四边边距、原点与窗口坐标，右键拷贝
- App 自定义属性：实现 `@objc lumen_debugInfo()` 把业务状态显示在检查器最前面，带 setter 的项可直接修改；`+lumen_colorAliases` 为颜色显示设计色别名
- `contentMode`、`textAlignment` 等枚举显示名称并可下拉修改；控件新增“事件处理”栏；实例变量显示持有者，继承链显示所在镜像
- 值为 nil 的颜色与文本可以直接编辑

### 画布与大纲
- 画布工具条贴在上缘，底部新增路径栏（从根到所选节点逐段可点），缩放百分比；加载进度、阶段与耗时显示在状态栏
- 按 `layer.mask` 裁剪，网页、Metal、视频、Lottie 图层内容完整显示；无内容图层可选透明、只描边框或淡色底板
- 3D 改为透视投影，分层跟随大纲的展开与折叠；层间距快捷键 ⌘[ / ⌘]；测量分关闭、父视图边距、锁定两节点三档
- 层级深度预设（⌥⌘1…⌥⌘5）、聚焦模式（只看某个节点的子树）、按 App 记住展开状态、键入类名前缀定位；顶层列出 `UIWindowScene` 与 Layout Guide；层级很深时缩进自动收窄
- 搜索结果在画布上着色并可下钻；悬停大纲行时画布同步高亮

### 诊断与连接
- 审计新增遮罩诊断：找出被 mask 整个挡住或只露出一小部分的视图，给出原因与修复建议
- 目标退出、崩溃或断网时保留现场：最后的层级、详情与纹理只读显示，可另存为 `.lumen` 快照，App 重新出现后自动切回实时
- 控制台方法名预测与 Tab 补全，参数按签名逐个填写，返回的对象可以继续调用
- 协议版本不兼容的 App 也出现在列表中，并说明该升级哪一方

### 界面
- 界面语言（简体中文、English、繁體中文）、外观（跟随系统、浅色、深色）与更新设置
- 设置中的“签名与调试”拆为“签名”与“真机调试”两页

### 修复
- 检查器单元格复用后 frame / bounds 等两行属性的第二行被裁掉；可编辑输入框单击即可进入编辑
- 窗口 hook 库让被调试的 iOS 包启动即崩溃
- 启动调试窗口拖放 ipa 时的约束冲突；脚本在 C locale 下报 unbound variable

### 安全
- 恶意 `.ipa` 借路径穿越或符号链接改写包外文件；bundle ID 与图标名做合法性校验
- 遮罩 alpha 位图的解压炸弹；日志推送的畸形位置让客户端崩溃
- 经对象句柄调用安全输入框相关对象时，返回的字符串仍以掩码返回
- 经“启动调试”安装到真机的副本会开启局域网连接以便 Wi-Fi 发现，请在可信网络中调试

### 性能
- 采集端日志历史裁剪、遮罩 alpha 位图生成、描边形状层溢出判断大幅提速
- 大纲展开记忆与结构路径查询在大层级下不再卡顿
