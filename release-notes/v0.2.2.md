## Lumen 0.2.2

### 新功能
- 目标选择改为卡片网格：按平台分组、按设备归类，标明 USB / Wi-Fi / 局域网 / 模拟器 / 本机，卡片显示主窗口预览；工具栏选择器弹出同样的切换面板，当前目标带选中态
- 手势：大纲行首的竖条标出挂有手势识别器的视图，点按弹出手势面板，列出类名、父类、持有它的实例变量、状态、代理、目标与操作，可直接开关手势；属性面板的手势改为卡片，文字可拖选复制
- 屏蔽的类：在设置中维护要屏蔽的类，画布不渲染命中节点及其子树，大纲灰显标识，可临时显示、重新屏蔽或一键屏蔽此类
- 加载与刷新时显示进度浮层：层级与纹理进度、实时耗时与图层数
- 目标 App 进入后台或被挂起时给出提示与重试，恢复后自动重新拉取详情、层级与纹理
- 画布“定位”后目标图层闪烁高亮

### 界面
- 设置窗口改为工具栏标签页（通用、源码定位、屏蔽的类、层级树），新增层级树字号、行高与层级引导竖线设置
- 层级树完整显示每行信息，宽度不够时横向滚动
- 主界面加毛玻璃底，画布背景半透明（开启“降低透明度”时保持不透明）
- 外观覆盖菜单标明各平台支持项与不支持原因，提供全部恢复

### 修复
- 还原 iOS 26 / 27 标签栏的液态玻璃底板与选中镜片，修复分层视图中黑色胶囊与白色模板字
- 系统配置了 SOCKS / HTTP 代理时，连接始终直连目标，不可达的目标不再被误判为已连接
- App 重启后手动刷新只更新部分图层
- 切换目标面板中第一张卡片显示焦点环

### 安全与性能
- 对端发来的预览图与纹理只解码 PNG，并限制大小
- 大纲列宽只重新测量内容变化的行，上万节点时展开、过滤、屏蔽与缩放窗口不再卡顿；纹理加载进度统计改为增量计数

### 命令行与 AI 助手
- 层级与节点输出带 `gestures=` 字段（JSON 中为 `gestures` 数组），帮助与 MCP 工具说明同步更新
